============================================================
   راهنمای سیم‌کشی ESP8266 فن کنترلر — نسخه ساده
============================================================

این فایل رو کنار فایل esp8266_firmware.ino بذارید.

------------------------------------------------------------
۱. قطعات لازم
------------------------------------------------------------

  - ۱ عدد NodeMCU v1.0 یا Wemos D1 Mini (ESP8266)
  - ۲ عدد فن ۴-پین PWM (CPU و GPU)
  - ۲ عدد مقاومت ۱۰ کیلو اهم (۱/۴ وات)
  - ۱ دکمه فشاری کوچک (۶×۶ میلی‌متر)
  - سیم DuPont یا سیم نازک
  - کابل USB Micro (برای برنامه‌ریزی و تغذیه ESP)
  - یه سیم از PSU کامپیوتر (Molex یا SATA) برای ۱۲ ولت

------------------------------------------------------------
۲. شماتیک اتصالات (مهم‌ترین بخش)
------------------------------------------------------------

  ┌─────────────────────────────────────────────┐
  │              NodeMCU Pinout                 │
  │                                             │
  │  D1 (GPIO5)  ──── پین PWM فن CPU             │
  │  D2 (GPIO4)  ──── پین PWM فن GPU             │
  │  D5 (GPIO14) ─── دکمه Game Mode             │
  │  D6 (GPIO12) ─── پین Tach فن CPU (RPM)      │
  │  D7 (GPIO13) ─── پین Tach فن GPU (RPM)      │
  │  D4 (GPIO2)  ──── LED روی خود برد            │
  │  Vin ─────────── ۵ ولت (از USB یا PSU)      │
  │  GND ─────────── مشترک با PSU و فن‌ها        │
  └─────────────────────────────────────────────┘

  نکته: پین Tach (سبز) برای خواندن RPM هست.
  اگه نمی‌خواید RPM رو ببینید، می‌تونید این پین‌ها رو وصل نکنید.

------------------------------------------------------------
۳. اتصال فن‌ها
------------------------------------------------------------

  فن ۴-پین استاندارد این پایه‌ها رو داره:

    ┌──────┬──────┬──────┬──────┐
    │  ۱   │  ۲   │  ۳   │  ۴   │
    │ GND  │ 12V  │ Tach │ PWM  │
    │مشکی │ زرد  │ سبز │ آبی  │
    └──┬───┴──┬───┴──┬───┴──┬───┘
       │      │      │      │
       │      │      │      └── به D1 (CPU) یا D2 (GPU) NodeMCU
       │      │      │          + مقاومت ۱۰k به GND (pull-down)
       │      │      │
       │      │      └── (اختیاری) برای خواندن RPM — وصل نمی‌کنیم
       │      │
       │      └── به ۱۲ ولت PSU (سیم زرد Molex یا SATA)
       │
       └── به GND مشترک (PSU + NodeMCU)


  مثال اتصال فن CPU:

     PSU 12V (زرد) ──────────────── ۱۲V فن (زرد)
     PSU GND (مشکی) ─────────────── GND فن (مشکی)
                                       │
                                       └── NodeMCU GND  ← (GND مشترک!)

     NodeMCU D1 ─────┬─────── PWM فن (آبی)
                     │
                     │
                    ┌┴┐
                    │ │  مقاومت ۱۰ کیلو اهم
                    │ │
                    └┬┘
                     │
                    GND (مشترک با PSU)


  مثال اتصال فن GPU:

     PSU 12V ────────────────────── ۱۲V فن GPU
     PSU GND ─────────────────────── GND فن GPU

     NodeMCU D2 ─────┬─────── PWM فن GPU
                     │
                    ┌┴┐
                    │ │ ۱۰k
                    └┬┘
                     │
                    GND

------------------------------------------------------------
۴. اتصال دکمه Game Mode
------------------------------------------------------------

  دکمه ۴ پایه داره. پایه‌های قطری رو استفاده کنید:

     NodeMCU D5 (GPIO14)
         │
         │
       ┌─┴─┐
       │   │  دکمه فشاری ۶×۶
       │   │
       └─┬─┘
         │
        GND

  - کوتاه فشار: Game Mode روشن/خاموش
  - بلند فشار (۱.۵ ثانیه): به پروفایل Silent برگرد

------------------------------------------------------------
۵. اتصال تغذیه
------------------------------------------------------------

  دو راه برای تغذیه NodeMCU:

  روش ۱ (ساده): از USB کامپیوتر
    - کابل USB Micro به NodeMCU وصل کنید
    - این هم برای برنامه‌ریزی و هم تغذیه استفاده می‌شه
    - همزمان می‌تونید دما رو از طریق USB هم بفرستید

  روش ۲ (پایدارتر): از PSU کامپیوتر
    - سیم قرمز ۵ ولت Molex → NodeMCU Vin
    - سیم مشکی GND → NodeMCU GND
    - این روش برای وقتیه که نمی‌خواید ESP به PC وصل باشه

------------------------------------------------------------
۶. GND مشترک (خیلی مهم!)
------------------------------------------------------------

  این مهم‌ترین نکته سیم‌کشیه:

     PSU GND ────┬──── NodeMCU GND
                 │
                 └──── فن CPU GND
                      فن GPU GND

  اگر GND مشترک نباشه:
  - فن‌ها ممکنه کار نکنن
  - PWM نویزی می‌شه
  - NodeMCU ممکنه ریست بشه

------------------------------------------------------------
۷. مونتاژ نهایی
------------------------------------------------------------

  ۱. کامپیوتر رو خاموش کنید
  ۲. PSU رو از برق بکشید
  ۳. صبر کنید ۳۰ ثانیه تا خازن‌ها خالی بشن
  ۴. سیم‌ها رو طبق شماتیک وصل کنید
  ۵. مطمئن بشید GND مشترک هست
  ۶. مقاومت‌های pull-down رو چک کنید
  ۷. PSU رو به برق وصل کنید
  ۸. کامپیوتر رو روشن کنید

------------------------------------------------------------
۸. تست سیستم
------------------------------------------------------------

  ۱. NodeMCU رو با USB به کامپیوتر وصل کنید
  ۲. Arduino IDE رو باز کنید
  ۳. Serial Monitor رو باز کنید (baud 115200)
  ۴. باید این خروجی رو ببینید:

     [BOOT] ESP8266 Fan Controller v2.0
     [AP] Hotspot started! IP=192.168.4.1
     [AP] SSID='FanController'  Pass='12345678'
     [BOOT] ready

  ۵. به وای‌فای "FanController" وصل بشید (رمز: 12345678)
  ۶. مرورگر رو باز کنید و برید به http://192.168.4.1/status
  ۷. باید JSON شبیه این ببینید:
     {"cpu_pct":50,"gpu_pct":50,"cpu_temp":0,"gpu_temp":0,...}

  ۸. حالا اپ FanController.exe رو اجرا کنید
  ۹. دما و سرعت فن‌ها رو ببینید

------------------------------------------------------------
۹. عیب‌یابی
------------------------------------------------------------

  مشکل: فن‌ها اصلا نمی‌چرخن
  راه‌حل: GND مشترک رو چک کنید. اگه GND مشترک نباشه کار نمی‌کنن.

  مشکل: فن‌ها همیشه ۱۰۰٪ می‌چرخن
  راه‌حل: مقاومت pull-down (۱۰k) رو بین پین PWM و GND اضافه کنید.

  مشکل: NodeMCU ریست می‌شه
  راه‌حل: از یه شارژر تلفن ۲ آمپر استفاده کنید (نه پورت USB کامپیوتر).

  مشکل: وای‌فای FanController پیدا نمی‌شه
  راه‌حل: Serial Monitor رو چک کنید. اگه "AP FAILED" دیدید، رمز رو
         حداقل ۸ کاراکتر کنید یا کانال وای‌فای رو عوض کنید.

  مشکل: اپ وصل نمی‌شه
  راه‌حل: مطمئن بشید به وای‌فای FanController وصل هستید. آیکون وای‌فای
         ویندوز رو چک کنید.

------------------------------------------------------------
۱۰. اطلاعات فنی
------------------------------------------------------------

  - فرکانس PWM: ۲۵ کیلوهرتز (استاندارد Intel PC fan)
  - رزولوشن PWM: ۱۰-بیت (۰-۱۰۲۳)
  - حداقل سرعت فن: ۱۰٪ (تا فن کاملاً خاموش نشه)
  - IP پیش‌فرض: 192.168.4.1
  - پورت WebSocket: ۸۱
  - پورت HTTP: ۸۰
  - SSID: FanController
  - رمز: 12345678

------------------------------------------------------------
۱۱. پروفایل‌های پیش‌فرض
------------------------------------------------------------

  پروفایل ۰ - Silent (آروم):
    دما ۳۰→۹۰°C = سرعت ۱۵→۹۵٪

  پروفایل ۱ - Balanced (متعادل - پیش‌فرض):
    دما ۳۰→۹۰°C = سرعت ۲۰→۱۰۰٪

  پروفایل ۲ - Performance (عملکرد):
    دما ۳۰→۸۰°C = سرعت ۳۰→۱۰۰٪

  پروفایل ۳ - Game (گیمینگ):
    دما ۳۰→۹۰°C = سرعت ۶۰→۱۰۰٪ (حداقل ۶۰٪)

------------------------------------------------------------
۱۲. دستورات سریال (USB fallback)
------------------------------------------------------------

  اگه وای‌فای قطع بشه، می‌تونید از USB کنترل کنید:

  - خواندن دما: {"cmd":"temps","cpu":52,"gpu":68}
  - تنظیم فن: {"cmd":"set","fan":"cpu","percent":80,"mode":"manual"}
  - Game Mode: {"cmd":"game","on":true}
  - تغییر پروفایل: {"cmd":"profile","id":2}
  - وضعیت فعلی: {"cmd":"status"}

  این دستورات رو در Serial Monitor ارسال کنید.
