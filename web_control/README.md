# 🌐 کنترل پنل وب - Fan Controller

این یه صفحه HTML خالص هست که **بدون نیاز به نصب**، مستقیم به ESP8266 وصل می‌شه.

## 🚀 استفاده

### روش ۱: باز کردن فایل
۱. فایل `control.html` رو با مرورگر باز کنید (دابل‌کلیک)
۲. به وای‌فای `FanController` (رمز: `12345678`) وصل بشید
۳. روی دکمه **«🔗 اتصال»** کلیک کنید

### روش ۲: از GitHub Pages
می‌تونید این فایل رو روی هر هاست وب (یا GitHub Pages) بذارید و از هر دستگاهی (موبایل، تبلت، کامپیوتر) به ESP8266 وصل بشید.

## ✨ ویژگی‌ها

- 🎨 **تم دارک** مشابه اپ ویندوز
- 🔄 **انیمیشن پره‌های فن** (با سرعت واقعی)
- 🌡️ **نمایش دما، سرعت و RPM** هر فن
- 🎚️ **اسلایدر** کنترل دستی سرعت
- 🎮 **دکمه Game Mode** و حالت اتوماتیک
- 📊 **انتخاب پروفایل** (Silent/Balanced/Performance/Game)
- 📋 **لاگ زنده** فعالیت‌ها
- 📱 **واکنش‌گرا** (روی موبایل هم کار می‌کنه)

## 🔗 پروتکل

از WebSocket (پورت ۸۱) و HTTP (پورت ۸۰) استفاده می‌کنه — همون پروتکلی که اپ ویندوز استفاده می‌کنه.

## ⚠️ نکات

- این صفحه **دما رو از PC نمی‌خونه** (مرورگر نمی‌تونه)
- فقط وضعیت فعلی ESP رو نشون می‌ده و کنترل می‌کنه
- برای خواندن دما از PC، باید اپ ویندوز رو اجرا کنید
- این صفحه برای کنترل دستی و موبایل عالیه
